# 🐾 Pet Care Management System

A full-stack web application that provides a complete platform for pet owners, veterinary professionals, trainers, groomers, adoption coordinators, and administrators to manage pet-related services efficiently.

## 📌 Features

### 🐶 Pet Management
- Register pets
- Edit pet information
- View pet profiles
- Lost & Found pet management
- Pet adoption system

### 📅 Appointment Management
- Veterinary appointments
- Grooming appointments
- Training appointments
- Home visit scheduling
- Appointment cancellation requests
- Appointment history

### 👨‍⚕️ Professional Module
- Professional registration
- Availability management
- Medical report generation
- Patient information
- Appointment management

### 🛍️ Pet Store
- Browse products
- Shopping cart
- Place orders
- Order management
- Sales reports

### 👤 User Features
- Authentication
- Dashboard
- Notifications
- Profile management

### 📊 Reports
- Appointment reports
- Sales reports
- Medical reports

## 🚀 Installation

### Clone Repository

```bash
git clone httpsgithub.comnazraizaPet-Care-Management-System.git
```

### Install Dependencies

Backend

```bash
cd backend
npm install
```

Frontend

```bash
cd frontend
npm install
```

Doctor Interface

```bash
cd docterInterface
npm install
```

---

## ▶️ Run Project

Backend

```bash
npm run dev
```

Frontend

```bash
npm run dev
```

Doctor Interface

```bash
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file inside the backend folder.

Example

```
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```
